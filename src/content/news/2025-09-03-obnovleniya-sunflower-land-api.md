На этой неделе команда **Sunflower Land** поделилась свежими новостями о разработке игры. Несмотря на «скелетный состав» в студии, работа идёт активно, и есть важные апдейты, которые порадуют игроков и разработчиков из сообщества.

---

### 🔧 Улучшения Community API

Команда занялась оптимизацией **Community API**, которое стало слишком медленным из-за роста данных (сотни тысяч ферм).

- Сейчас API ограничено 50–70 фермами за один запрос.
- Планируется экспорт больших массивов данных за один раз.
- При оптимизации нашли узкие места, например, неэффективную обработку инвентаря.

💡 Это даст ускорение не только API, но и работе серверов в целом.

---

### 🪙 SFL и мультичейн

Завершена миграция токена **SFL** — процесс прошёл успешно.

- Проблем не выявлено, перевод работает корректно.
- Теперь команда исследует новые возможности для мультичейна.
- Обсуждаются сети, куда можно будет расшириться после перехода с Polygon на Base.

---

### ⚒️ Ковка ресурсов (Node Forging)

Скоро появится новая механика — **ковка ресурсов**.

- Уже работает для камней.
- Планируется расширение на золото, железо и деревья.

Преимущества:

- экономия места на ферме;
- меньше кликов;
- упрощённый дизайн ферм.

Пример:

- 4 камня → один «уровень 2» с AOE ×4.
- 16 камней → «уровень 3» с ещё более мощным бонусом.

---

### 📊 Запросы от сообщества

Команда рассматривает предложения игроков:

- добавить в API данные о последних находках (например, из сундуков);
- интегрировать данные о ценах и предложениях SFT;
- вернуть API-информацию о подписках и фолловерах;
- улучшить индикаторы для животных (еда, уход, ласка).

---

### 🎶 Качество жизни и музыка

После релиза главы разработчики сосредоточатся на **quality-of-life улучшениях**:

- удобные индикаторы в амбаре и для животных;
- борьба с загромождёнными фермами;
- доработка музыки (сейчас она работает нестабильно).

---

### 📌 Итог

В ближайших обновлениях Sunflower Land можно ожидать:

- новый, более быстрый Community API,
- расширение мультичейн-возможностей,
- механику ковки ресурсов,
- улучшения интерфейса и животноводства.

Следить за новостями можно на еженедельных **Twitch-трансляциях**.
