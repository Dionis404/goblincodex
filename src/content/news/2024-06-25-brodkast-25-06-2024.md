#### Краткий обзор бродкаста.

Адам рассказал о многих моментах и пообщался с игроками.

Общие обновления:

- Улучшение производительности для разблокировки новых функций, включая многопользовательские аспекты.
- Обнаружено увеличение трафика, вызывающее ошибки; временно решено за счет улучшения производительности сервера.
- Команда работает над долгосрочными решениями с поставщиками программного обеспечения.

#### Опыт новых пользователей:

- Упор на улучшение опыта новых пользователей, чтобы сделать игру более доступной для широкой аудитории.
- Введение ежедневных доставок монет и дополнительных NPC для новых пользователей в первые семь дней.

#### Механика и функции игры:

- Улучшения домов фракций, включая индивидуальные украшения и носимые предметы.
- Завершается разработка механики кухни, дел и питомцев.
- Разрабатываются новые таблицы лидеров и еженедельные призы для соревнований фракций.

#### Запуск на мобильных устройствах и бесплатная версия:

- Планируется запуск бесплатной мобильной версии игры в конце этого года.
- Исследуются концепции, такие как ежедневные пакеты семян, для поддержания баланса между бесплатной игрой и экономикой игры.

#### Взаимодействие с сообществом:

- Программы рефералов для привлечения новых игроков.
- Открытые сессии вопросов и ответов для сбора отзывов и предложений от сообщества.

#### Событие по сбору пожертвований:

- Событие по сбору пожертвований для мини-игр: Пожертвования поддерживают разработчиков, предлагая разные призы каждый день.
- Новая технология порталов: Внедрение новой технологии порталов для мини-игр.

#### Обратная связь по игре:

- Положительный прием: Игра Sunflowerland получила положительные отзывы, с возрастающей сложностью и опциями риск-награда.
- Проблемы: Сообщения о периодических проблемах после обновления ПО.

#### Обновления серверов и фракций:

- Проблемы с сервером: Сообщалось о кратковременных сбоях; решаются проблемы с ЦП.
- Питомцы фракций: Анонсированы новые питомцы, включая величественного грифона для Sunflorians.
- Таблица лидеров: Вероятное внедрение таблицы лидеров для мини-игры Chicken Rescue.

#### Индивидуальные украшения и механика фракций:

- Улучшения: Индивидуальные украшения, NPC, питомцы и анимации для домов фракций.
- Обсуждения: Продолжаются обсуждения о питомцах, цветах и зонах действия.

#### Магазин королевства и предметы:

- Исследуйте магазин королевства: Различные предметы для фракций, включая предметы для повышения эффективности фермерства.
- Постоянные предметы: Введение постоянных предметов и предметов для изменения времени для преимущества в игре.

#### Еженедельная таблица лидеров фракций и обновления:

- Миссии и метки: Выполняйте миссии фракций, чтобы зарабатывать метки и подниматься в таблице лидеров.
- Балансировка: Корректировка требований к эмблемам на основе отзывов сообщества.

#### Упрощенная фермерская игра:

- Казуальная игра: Акцент на казуальном фермерстве, вдохновленная K-Day и Township.
- Коллекции NFT: Игроки могут торговать и собирать сезонные NFT с 10 уровня.

#### Свитки и стратегия:

- Свитки: Используются для покупок и участия в торгах на редкие предметы.
- Стратегическая игра: Сочетание казуального фермерства и соревновательных элементов.

#### Игры Web 3:

- Собственность: Технология Web 3 позволяет игрокам владеть внутри игровыми покупками.
- Адаптация: Предложения по привлечению большего числа пользователей с помощью бесплатных начальных наград.

#### Проблемы с бесплатными играми:

- Слабость Элементы игры за деньги рассматриваются как проблема.
- Мобильная версия Планы по запуску бесплатной мобильной версии.

#### Преимущества реферального кода приложения:

- Стимулы, бесплатный старт и бонусные монеты с реферальным кодом; стимулирование устного участия.

#### Адаптация казуальной игры:

- Получение ресурсов, получение ценных ресурсов имеет решающее значение.
- Адаптация: Продолжаются усилия по улучшению процесса адаптации.

#### Обновления игры для новых пользователей:

- Улучшения: Доступные поставки монет и дополнительные NPC для получения большего количества монет.
