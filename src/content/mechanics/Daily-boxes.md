> ⚡ **Кратко:** Каждый день входа приносит награду. Новые игроки получают особый набор на первые 7 дней, а долгие стрики открывают эксклюзивные бонусы.

## Первые 7 дней

Для **новых игроков** — отдельный набор наград:

| День | Награда | Описание |
|------|---------|----------|
| 1 | Basic Farming Pack | Семена и фермерские ресурсы |
| 2 | Builder Basics | Строительные ресурсы |
| 3 | Basic Love Box | Базовый Love Box |
| 4 | Tool Tune-Up | Инструменты |
| 5 | Базовые монеты | — |
| 6 | Fishing Pack | Предметы для рыбалки |
| **7** | **First Week Finale** | **Weekly Mega Box + Gem** |

## Награда 7-го дня

**Weekly Mega Box** содержит одну из следующих наград:

| Предмет | Количество |
|---------|------------|
| Coins | 1 000 / 2 500 / 5 000 |
| Fishing Lure | ×5 |
| Gem | 100 или 500 |

## Остальные дни

Награды чередуются и масштабируются с уровнем игрока:

| Награда | Описание |
|---------|----------|
| **Coin Stash** | Монеты. Формула: `Math.floor(500 * (level / 25))` |
| **Growth Feast** | Зелье опыта. На 90 ур. даёт ~6.46% до следующего уровня — процент снижается по мере роста |
| **Growth Boost** | Power Hour: +50% скорости роста, +0.2 к сбору урожая на 1 час |
| **Tool Cache** | Axe, Pickaxe, Iron Pickaxe — количество зависит от уровня |
| **Love Box** | Basic / Bronze / Silver в зависимости от уровня игрока |
| **Angler Pack** | Rod, Earthworm, Grub — количество зависит от уровня |

> 💡 Чем выше уровень персонажа — тем больше ресурсов в каждой награде, но тем меньший процент опыта даёт Growth Feast.
